# apps/mobile — Мобильный клиент

Цель — приём ссылки из TikTok через системный share sheet в ≤ 2 тапа (US-1 в `docs/03-tz.md`) и оффлайн-просмотр локальной библиотеки.

- Стек: Flutter (iOS + Android одной кодовой базой).
- Примечание: до Фазы 2 роль мобильного канала выполняет Telegram-бот + PWA.

Статус: Фаза 2.
