# apps/web — Веб-панель библиотеки

Лента-сетка карточек, приём ссылок, папки/теги, плеер (локальный файл + embed TikTok), заметки, транскрипт, поиск с операторами — **каркас реализован**.

- Стек: Next.js 15, React 19, **static export** (`out/`) — раздаётся FastAPI в одном контейнере (docs/09 §9.10); PWA manifest.
- API-клиент: `src/lib/api.ts` (Bearer-токен из localStorage; медиа — `?token=`), типы — `src/lib/types.ts` (зеркало pydantic-схем; генерация из OpenAPI — дальше).
- SSE `/api/events` обновляет ленту при смене статусов обработки.

Запуск в разработке: `npm install && npm run dev` (rewrites `/api` → `http://127.0.0.1:8000`).
Прод-сборка: `npm run build` → `out/`, подхватывается сервером через `TOKLIB_WEB_DIST`.

Статус: Фаза 1 — базовая панель готова; далее: вертикальная лента «как в TikTok» (FR-4.2), массовые операции, drag&drop, импорт/экспорт в UI.
