# integrations/homeassistant — Кастомная интеграция HA

HACS-компонент, говорящий с API TokLib:

- сенсоры: новые в инбоксе, непросмотренные, мёртвые ссылки;
- сервисы: `add_url`, `search`;
- MediaSource: библиотека в медиабраузере HA → просмотр на TV, кастинг на Chromecast;
- примеры автоматизаций: вечерний дайджест непросмотренного.

Требования: FR-8.1 в `docs/03-tz.md`. Статус: Фаза 3.
